Use it

Two ways in.

Payments use the open x402 protocol: the API answers 402 with the price, your client signs a USDC authorization and retries. An unknown slug returns 404 before any payment is requested.

Claude, via MCP

Three tools: the catalog and the sample are free, records cost $0.01 from a wallet key you set, with a hard cap per call. Use a dedicated wallet with a few dollars in it.

claude mcp add underindex -e UNDERINDEX_PRIVATE_KEY=0x... -- npx -y underindex-mcp

Claude Desktop config, full setup:

"underindex": {
  "command": "npx",
  "args": ["-y", "underindex-mcp"],
  "env": { "UNDERINDEX_PRIVATE_KEY": "0x..." }
}

Any x402 client

Works with @x402/fetch, Coinbase AgentKit and any agent that speaks x402.

import { x402Client, wrapFetchWithPayment } from "@x402/fetch";
import { registerExactEvmScheme } from "@x402/evm/exact/client";
import { privateKeyToAccount } from "viem/accounts";

const client = new x402Client();
client.setSpendControls({ maxAmountPerPayment: "$0.05" });
registerExactEvmScheme(client, {
  signer: privateKeyToAccount(process.env.EVM_PRIVATE_KEY),
});
const pay = wrapFetchWithPayment(fetch, client);
const res = await pay(
  "https://underindex-api.onrender.com/api/subculture/acubi-style"
);
console.log(await res.json());

Endpoints

Reference.

  • GET /api/catalogfreeEvery slug with its name and years, plus the dataset version and price.
  • GET /api/samplefreeOne complete record (Goth Ninja), in the paid shape.
  • GET /api/free/subculture/{slug}3 free a dayAny record without a wallet, 3 per day per client. Answers 429 once used, with the time it resets.
  • GET /api/subculture/{slug}$0.01The full record. Also served as /api/subculture?name={slug}.
  • GET /openapi.jsonfreeOpenAPI 3.1 with x402 payment info and every valid slug.
